## Подпись и хранение

С явного разрешения владельца создан отдельный ключ MaxMusic: RSA 3072, SHA256withRSA, alias maxmusic, PKCS12. Публичный сертификат `CN=Gevork Saturn, OU=MaxMusic, O=SATURN`, срок до 18 октября 2056.

Ключ сохранён отдельно от исходников в зашифрованном PKCS12. Случайный пароль не записывался открытым файлом. Ключ и пароль дополнительно защищены Windows DPAPI CurrentUser; доступ к закрытой папке ограничен текущим пользователем и SYSTEM. Зашифрованная резервная копия совпадает с основным ключом. Восстановление DPAPI-конверта проверено.

Переносимый экспорт с отдельным паролем использует стандартные .NET PKCS12 API, AES-256, PBKDF2 SHA-256 (600000 итераций) и MAC SHA-256. На временной зашифрованной копии проверены восстановление закрытого ключа в Windows, импорт Java keytool, alias maxmusic и совпадение публичного сертификата. Временная тестовая копия удалена. Пароль экспорта не сохраняется и не выводится. Перед переустановкой Windows или переносом на другой компьютер владелец должен сформировать переносимую копию и отдельно сохранить выбранный пароль.

Закрытые ключи, DPAPI-конверты, пароли, локальные пути SDK и результаты сборки не входят в архив исходников. Публичный сертификат включён. Для GitHub предназначены исходники и APK; закрытая папка подписи не предназначена для публикации.

Для 0.1.0 интерфейс проверен в Chromium 393×844 с имитацией нативного моста: управление воспроизведением, перемотка на 60 секунд, светлая и системная темы, создание плейлиста, отсутствие переполнения по ширине, экранирование HTML в названиях. После неё менялась подпись, тип сборки и номер версии; полная проверка браузера повторно не запускалась.

Заставка в макете: 300 мс, все пять анимаций помех 300 мс. Исправление короткого хвостика M перенесено в Android-интерфейс.

## Требует реального устройства и аккаунта

Телефон друга TECNO POVA 6 Pro отсутствовал; эмулятор не запускался. Установка, вход в VK, доступ к каталогу, слышимый звук, работа при блокировке экрана, Bluetooth, скачивание MP3/HLS, автономное воспроизведение и энергосбережение HiOS ещё требуют проверки на телефоне.

Отсутствие рекламы, снятие ограничений VK и полная совместимость с указанным телефоном не подтверждены. Приложение запрашивает доступные пользовательской сессии данные и потоки, при отказе VK показывает ошибку.

Тестовая 0.1.0 подписана другим ключом. Обычное обновление с неё на 0.1.1 не поддерживается; переустановка удалит локальные данные. Для будущих обычных обновлений нужно сохранять постоянный ключ MaxMusic и увеличивать versionCode.
