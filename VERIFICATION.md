# Проверка MaxMusic 0.1.2

18 октября 2026, Europe/Moscow.

## Исправления по записи пользователя

Заставка удалялась повторной отрисовкой приложения во время bootstrap/обновления библиотеки. Теперь её DOM сохраняется отдельно от содержимого; отсчёт 300 мс начинается после подтверждения готовности кадра WebView и следующих кадров браузера. Начальная отрисовка не ждёт чтения библиотеки.

Адаптивный отступ `.screens` из макета создавал лишние 22 пикселя и прокрутку окна. Корневой размер привязан к доступной области WebView, прокручивается только `.scroll` либо содержимое полного плеера. Шапка и навигация остаются на месте.

Нативное окно явно обрабатывает system bars, display cutout и IME. Применённые отступы поглощаются до WebView, фон под прозрачными системными панелями и цвет их значков меняются вместе с темой. Отключена внешняя прокрутка WebView.

## Ограничение проверки

Проверки UI используют имитацию нативного моста, Robolectric моделирует Android. Исправленная версия на физическом телефоне не запускалась. Присланная запись исходной 0.1.1 использована только локально для диагностики и не включена в исходники или GitHub.

Сценарии входа VK, звука, скачивания и фоновой работы повторно не проверялись; их реализация не менялась. Пользовательская запись подтверждает запуск исходной версии, но не работу перечисленных аудиофункций.

APK подписан прежним постоянным ключом MaxMusic; закрытый ключ и пароли не включены в исходники. Зашифрованная резервная копия уже хранится отдельно. Для обновления с 0.1.1 удаление приложения не требуется. Более ранняя debug-версия 0.1.0 подписана другим ключом.

## Воспроизведение автоматической UI-проверки

`npm install --no-save playwright` и `node tools/check-ui.cjs` при установленном Microsoft Edge. Нативные тесты: `./gradlew :app:testReleaseUnitTest`. Перед сборкой UI: `node tools/prepare-ui.cjs`.
