0.1.2 подписана тем же сертификатом, что 0.1.1: устанавливайте обновлением поверх неё.

## Установка

1. Передайте другу только файл `MaxMusic-0.1.2.apk` и откройте его на телефоне.
2. Если Android спросит, разрешите установку для приложения, которым открыт APK.
3. В MaxMusic нажмите «Войти в VK», завершите вход на странице VK и нажмите «Готово» сверху.

Для локальных файлов вход не нужен: «Добавить музыку с телефона».

Если уже установлена тестовая версия 0.1.0 с подписью Android Debug, обычное обновление на 0.1.2 не поддерживается: у них разные ключи. Для новой установки потребуется удалить тестовую сборку; её локальные данные при этом удаляются. Последующие версии, подписанные постоянным ключом MaxMusic и имеющие больший versionCode, предназначены для обычного обновления.

## Что реализовано

- Согласованный интерфейс, логотип MAX MUSIC и заставка с помехами на 0,3 секунды.
- Тёмная, светлая и системная тема; красный, жёлтый, зелёный и синий акценты.
- Нативный аудиодвижок Media3/ExoPlayer в отдельной службе Android.
- Очередь, пауза, перемотка, переключение треков, повтор, перемешивание и системное управление воспроизведением.
- Получение библиотеки, чтение плейлистов и поиск VK через веб-сессию пользователя.
- Скачивание доступных потоков MP3/HLS, список музыки без сети.
- Импорт аудиофайлов через системный выбор файлов, локальное избранное и собственные плейлисты MaxMusic.
- Цвета полного и мини-плеера по изображению обложки.

## Границы проверки

Телефон друга TECNO POVA 6 Pro во время разработки отсутствовал. APK нельзя считать проверенным на нём.

Сборка, анализ Android и автоматические проверки интерфейса и данных описаны в приложенном отчёте проверки. Эти проверки не заменяют воспроизведение на настоящем телефоне.

Авторизация в VK с аккаунтом друга, выдача треков VK, фоновая работа при блокировке экрана, загрузка HLS и поведение энергосбережения HiOS требуют проверки на телефоне. Доступ без рекламы и ограничений не подтверждён. VK может ограничить веб-сессию, потребовать капчу или изменить методы доступа.

Приложение не содержит демонстрационных треков и не показывает вымышленное воспроизведение. Если VK не выдаёт доступ, выводится ошибка VK.

В этой сборке одна очередь содержит до 200 треков, поиск возвращает до 100 результатов, чтение одного плейлиста VK ограничено 6000 треками. Большая библиотека подгружается кнопкой «Загрузить ещё».

## Данные

Пароль вводится на странице VK в отдельном WebView без интерфейса JavaScript к приложению. Токен хранится в закрытой памяти приложения с шифрованием Android Keystore. Внешнего сервера MaxMusic, аналитики и рекламных SDK нет. Cookie входа остаются в хранилище WebView этого приложения. Выход удаляет сессию VK; скачанные файлы и собственная музыка сохраняются.

## Сборка

JDK 17, Android SDK 35, Build Tools 35.0.1, Gradle 8.9, Node.js для подготовки интерфейса.

```
node tools/prepare-ui.cjs
./gradlew :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
```

Для своей release-подписи используются переменные `MAXMUSIC_KEYSTORE` (путь к PKCS12) и `MAXMUSIC_STORE_PASSWORD` (пароль только в окружении процесса), alias `maxmusic`. Затем выполните `./gradlew :app:assembleRelease`. Без этих переменных `assembleRelease` создаёт неподписанный APK. Секреты нельзя включать в репозиторий или архив исходников.

На Windows владелец MaxMusic может использовать `tools/sign-release.ps1 -SigningEnvelope <путь-к-MaxMusic-signing-key.dpapi>`. Рядом с конвертом должен находиться зашифрованный `MaxMusic-release.p12`. Пароль расшифровывается средствами Windows только в памяти процесса. Оба файла хранятся отдельно от исходников. DPAPI-конверт привязан к текущей учётной записи Windows; перед переустановкой Windows или переносом на другой компьютер нужна переносимая копия с отдельным паролем.

Для переносимой копии из текущей учётной записи Windows: `tools/export-portable-key.ps1 -SigningEnvelope <путь-к-MaxMusic-signing-key.dpapi> -Destination <путь-к-новому-backup.p12>`. Нужен PowerShell 7. Утилита запрашивает новый пароль без отображения, сохраняет PKCS12 с AES-256 и проверяет восстановление; пароль не записывается в файл. Сохраните пароль отдельно, а переносимую копию вне этого компьютера. Совместимость копии с Java keytool и alias `maxmusic` проверена. Сами ключи и DPAPI-конверт в этот архив не входят.

Публичный сертификат включён в `signing-certificate.pem`. SHA-256 сертификата: `B08850194E55CA28A98A75785D0B7F6A523A7B473E3002E8A2E246D8B3ADD993`. Владелец: `CN=Gevork Saturn, OU=MaxMusic, O=SATURN`, RSA 3072, срок до 18 октября 2056. Публичный сертификат не позволяет подписывать обновления без закрытого ключа.

В `local.properties` укажите `sdk.dir` своей Android SDK. `design.html` содержит утверждённый макет; `tools/prepare-ui.cjs` переносит его оформление в приложение. Регрессионная проверка интерфейса: `npm install --no-save playwright`, затем `node tools/check-ui.cjs`. Нужен установленный Microsoft Edge; тест использует имитацию нативного моста, не аккаунт VK. Результат по умолчанию записывается в `ui-checks.json`.

Нативный код: `app/src/main/java/com/saturn/maxmusic/`. Рабочие команды интерфейса: `tools/runtime.js`.

Протокол веб-сессии и работа с современным API VK адаптированы из [ilyhalight/vk-audio](https://github.com/ilyhalight/vk-audio), MIT. Нативное воспроизведение: [AndroidX Media3](https://github.com/androidx/media), Apache 2.0. Загрузка локального интерфейса: AndroidX WebKit, Apache 2.0. Лицензии включены в `app/src/main/assets/` и архив исходников.
